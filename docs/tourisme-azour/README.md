# Plateforme touristique d'Azour

Nouveau chantier du programme CEM Liban (triade Villepreux · Azour ·
LEY) : offrir aux visiteurs une plateforme web/app qui présente les
parcours, informe et accompagne sur le terrain — et qui soit pensée pour
être dupliquée (Jeïta, caza de Jezzine, échelle nationale à terme).

Dossier ouvert le 29/08/2026.
