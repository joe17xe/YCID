# Tests Solid'Pilot — Maria Maroun

Bonjour Maria,

Vous intervenez avec deux rôles différents selon le projet :
**Terrain (contributeur)** sur la Triade Villepreux · Azour · LEY, et
**Chef de projet** sur la Coordination. Les tests ci-dessous portent sur
la Triade Villepreux, donc sur votre rôle Terrain.

Ces tests portent sur votre travail quotidien : suivre les tâches,
justifier ce qui est fait, tenir le budget. Le but n'est pas de vérifier
du code, c'est de savoir si **vous pouvez faire votre travail avec cet
outil**.

Comptez **30 à 45 minutes**. Faites-en autant que vous pouvez ; ce qui
compte le plus est marqué ⭐.

## ⚠️ Deux choses à ne pas faire

- **Ne supprimez pas de projet** (bouton définitif).
- Ne supprimez pas de tâches, pièces ou lignes budgétaires que vous
  n'avez pas créées pendant ces tests.

Tout ce que vous créez ci-dessous, vous pourrez le retirer ensuite.

---

## M1. Connexion et menu

1. Connectez-vous.
2. Regardez le menu de gauche (ou ☰ sur téléphone).

**Notez ce que vous voyez**, en particulier si une section
**Administration** (Utilisateurs, Stockage, Configuration) apparaît.

Nous savons déjà qu'elle est visible aujourd'hui : votre compte porte un
rôle global « YCID » plus large que votre fonction. Ce n'est pas une
erreur de votre part et le sujet est en cours de traitement — **n'entrez
pas dans ces écrans**, ils ne vous concernent pas.

## M2. Vos projets

1. Menu **Projets**.

**Attendu** : vous êtes membre de **2 projets** — la Triade Villepreux
(Terrain) et la Coordination (Chef). Un troisième peut apparaître du fait
de votre rôle global ; ne vous en étonnez pas.

2. Ouvrez **CEM Liban — Triade Villepreux · Azour · LEY**.
3. Onglet **Aperçu**.

**Attendu** : les organisations partenaires et les membres, dont vous.
Votre rôle y est affiché **« Terrain »** — c'est bien le vôtre sur ce
projet, ce n'est pas une erreur.

## M3. ⭐ Vos tâches

1. Onglet **Tâches**.

**Attendu** : les phases (Action 1, 2, 3), chacune dépliant ses tâches
avec statut, échéance et avancement.

2. Trouvez la tâche qui vous est assignée : **« Réalisation de la
   sécurisation du site »** (Action 1). C'est la seule à votre nom sur
   ce projet, inutile d'en chercher d'autres.
3. Cliquez sur le crayon pour la modifier.
4. Changez l'**avancement** (par exemple 0 % → 20 %) et enregistrez.

**Attendu** : le pourcentage de la tâche change, et celui de la phase
au-dessus se recalcule.

5. Remettez la valeur d'origine.

**Question de fond** : les informations affichées sur une tâche
vous suffisent-elles pour savoir où vous en êtes ? Que manque-t-il ?

## M4. ⭐ Justifier une tâche faite

C'est le cœur de ce qu'on vous demandera : prouver, pas seulement
déclarer.

1. Sur une tâche, cliquez sur **« + pièce »**.
2. Choisissez un fichier (photo, PDF, peu importe — moins de 10 Mo).
3. Nature : **Justificatif**. Déposez.

**Attendu** : la tâche passe de « 0 doc » à « 1 doc ».

4. Cliquez sur le compteur pour déplier, puis sur le **nom du fichier**.

**Attendu** : le document s'ouvre dans un nouvel onglet.

5. Repérez une tâche **terminée** qui n'a aucune pièce jointe.

**Attendu** : elle porte un badge orange **« sans justificatif »**, et
l'en-tête de la phase indique « N sans justificatif ». S'il n'y en a
aucune dans cet état, passez ce point — cela veut dire que tout est
justifié.

**Question** : ce signalement vous paraît-il utile ou pénible ? Il est
volontairement non bloquant — vous pouvez marquer une tâche terminée sans
pièce, on vous le signale seulement.

## M5. ⭐ Photos avant / après

Pour les chantiers, c'est la meilleure preuve.

1. Onglet **Tâches**, sous la barre d'avancement d'une phase, cliquez
   sur **« Ajouter une photo »**.
2. Choisissez une photo, moment **« Avant »**. Déposez.
3. Recommencez avec **« Après »**.
4. Dépliez la galerie.

**Attendu** : trois colonnes — Avant, Pendant, Après — avec vos photos
dans les bonnes colonnes.

5. **Test important** : refaites-le avec une photo **prise directement
   depuis votre iPhone**, sans la convertir.

**Ce qu'on cherche à savoir** : la photo se dépose-t-elle ? La vignette
s'affiche-t-elle, ou voyez-vous un carré vide / une image cassée ?
Précisez si vous êtes sur iPhone (Safari) ou sur un autre navigateur —
c'est déterminant.

## M6. Le budget de votre projet

1. Onglet **Budget**.

**Attendu** : les lignes regroupées par phase, avec pour chacune trois
colonnes : **Prévu**, **Engagé**, **Payé**.

**Question** : comprenez-vous ces trois mots sans qu'on vous les
explique ? Si un doute subsiste, dites lequel.

2. Regardez une tâche dans l'onglet Tâches : elle affiche un montant
   (parfois 0 €).

**Attendu** : ce montant correspond à ce que les lignes budgétaires lui
affectent.

## M7. Relier une tâche et un budget

⚠️ **Ce test peut vous être refusé, et c'est normal** : créer une ligne
budgétaire est réservé au chef de projet et au responsable financier.
Avec votre rôle Terrain sur ce projet, le bouton peut être absent ou
l'enregistrement refusé. Dites-moi simplement ce que vous constatez —
c'est une information utile, pas un échec.

1. Onglet **Tâches**, sur une tâche affichant **0 €**, cliquez sur
   **« + ligne budgétaire »**.

**Attendu** : le formulaire s'ouvre avec la phase déjà remplie et votre
tâche déjà présente dans « Tâches financées ».

2. Remplissez : Poste « Test Maria — à supprimer », Montant 100 €, et
   dans « Tâches financées » mettez 100 €. Créez.

**Attendu** : la tâche affiche maintenant 100 € au lieu de 0 €.

3. Rouvrez la ligne (crayon) et essayez de mettre **150 €** dans la
   répartition alors que la ligne vaut 100 €.

**Attendu** : un compteur passe en rouge et le bouton Enregistrer devient
inactif — impossible de répartir plus que le montant de la ligne.

4. Remettez 100 €, enregistrez, puis **supprimez cette ligne de test**.

## M8. Déposer une facture

1. Onglet **Budget**, sur une ligne, cliquez sur l'icône trombone 📎.
2. **Déposer une pièce** : choisissez un fichier, Nature **Facture**,
   Montant 200 €. Déposez.
3. Cliquez sur **« Marquer payée »**.

**Attendu** : un champ **date** apparaît (pas une fenêtre grise du
navigateur), pré-rempli à aujourd'hui. Confirmez.

**Attendu** : la mention « payé le … » apparaît, et la colonne **Payé**
de la ligne se met à jour.

4. **Annuler le paiement**, puis supprimez la pièce de test.

## M9. Retrouver un document

1. Onglet **Documents**.

**Attendu** : toutes les pièces du projet au même endroit, avec pour
chacune ce à quoi elle est rattachée.

2. Dans **Rechercher**, tapez un mot d'un titre de tâche.

**Attendu** : les pièces de cette tâche remontent.

3. Cliquez sur **Réinitialiser**.

**Attendu** : tous les filtres se vident, y compris le champ de
recherche.

4. Cliquez sur **« Télécharger »** : une archive ZIP se télécharge.

**Attendu** : elle contient autant de fichiers que le bouton l'annonçait.

## M10. ⭐ Sur téléphone — le test le plus attendu

Vous travaillez sans doute davantage sur téléphone que sur ordinateur.
Ce test n'a jamais pu être fait.

1. Ouvrez l'application sur votre téléphone, **en portrait**.
2. Onglet **Budget**, cliquez sur le crayon d'une ligne.
3. Dans le champ **Poste**, tapez **au moins dix caractères**.

**Attendu** : le clavier reste ouvert du début à la fin, et le champ ne
se déplace pas sous vos doigts.

4. Faites la même chose dans le champ **Montant**.
5. Puis dans la zone **« Tâches financées »**, sur un champ Montant.

**C'est le cas le plus difficile** : la fenêtre change de hauteur pendant
que vous tapez.

**Si le clavier se referme à chaque lettre, dites-le tout de suite** —
c'est un défaut que nous pensons corrigé mais que personne n'a encore
vérifié sur un vrai téléphone.

6. Regardez aussi le haut de l'écran du projet : les boutons doivent être
   de petites icônes, sans déborder.

## M11. Le rapport d'expert IA

1. Sur le projet, bouton **Rapport d'expert IA** → **Générer**.
2. Patientez 30 à 60 secondes.

**Attendu** : un rapport structuré citant vos vraies phases et tâches.

**Question** : y reconnaissez-vous votre projet ? Le rapport dit-il des
choses justes ? S'il se trompe sur un fait, c'est important à savoir.

Pour chaque test qui ne se passe pas comme décrit : **le numéro** + ce
que vous avez vu. Une capture d'écran est idéale.

Et au-delà : **qu'est-ce qui vous manque pour travailler ?** Vous êtes la
personne qui utilisera cet outil au quotidien. Un écran mal fichu, une
information absente, une manipulation trop longue — dites-le, c'est
exactement ce qu'on cherche.

**Pensez à retirer** en fin de test : la ligne « Test Maria — à
supprimer », les pièces et photos que vous avez déposées.
